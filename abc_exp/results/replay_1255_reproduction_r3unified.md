## Which traces and which convention

Seven sources (R0 + 4 logged rounds; the paper reads Round 3): DeepSeek-V4-Flash, the first 78 rows of the DeepSeek-V4-Pro partial file, Gemma-4-31B-it, and the four Qwen3.5/3.6 rows. 1,255 usable debates = 999 local vLLM (Gemma 200 + Qwen rows 799) + 180 DeepSeek-V4-Flash + 76 DeepSeek-V4-Pro. Unusable rows (20 + 2 + 1) have all-None `initial_answers`.

Convention: standard endpoint = `majority_answer` recoded to Round 3 with alphabetic ties; initial majority = alphabetic-tie majority of `initial_answers`; R1 majority = alphabetic-tie majority of the Round-1 agent answers; collapse = R0 majority correct and endpoint wrong, correction = the reverse; a fired gate returns the R0 majority. DisagreementGate = freeze unless the three initial answers agree (`init_unanimous == 0`). Weight ladder = (r * prevented - lost) / N, break-even = lost / prevented.

Why the shipped `correction_preserving_policy_replay.json` does not show this: it globs every `debate_traces_*.jsonl` and now holds a 13-source, 2438-debate cohort; the 1,255 cohort exists only in git (80106ed) and in this script's output.
