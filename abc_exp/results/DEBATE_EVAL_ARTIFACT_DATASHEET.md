# Debate Evaluation Artifact Datasheet

## Motivation

This artifact supports the paper's evaluation protocol for multi-agent LLM debate. It is intended to help a follow-up lab reproduce the reported transition tables, apply the same collapse/correction accounting to a new model-scaffold pair, and distinguish selection-time risk measurement from runtime diagnosis and intervention replay.

## Composition

The artifact contains evaluation code, aggregate alpha statistics, derived result tables, provenance summaries, parser-failure and parser cell-stability audits, cost cards, prompt cards, machine-readable reuse-card fields, and validated Croissant/RAI metadata in `debate_eval_croissant_rai_metadata.json` with receipt `DEBATE_EVAL_CROISSANT_VALIDATION.md`. The open data tier (https://huggingface.co/datasets/XINLI1997/DebateLedger) holds every probe and debate trace in this release with the model-generated text fields set to `null`, which is enough to audit transition denominators and rebuild the derived tables. The full-text traces and the very-strong (convince-wrong) and social-pressure probe templates are in a gated tier (https://huggingface.co/datasets/XINLI1997/DebateLedger-gated) because they can be reused as a misleading-answer corpus. The primary six-model debate cohort was recorded with per-round answers only, so its traces and the per-debate R1 feature matrix derived from them contain no model text and are in the open tier.

The benchmark questions come from upstream public MCQ benchmarks, primarily MMLU-Pro for the headline audit, plus ARC-Challenge, GPQA Diamond, and TruthfulQA boundary or stress checks. The artifact does not claim ownership over those benchmark questions and should be used subject to their original licenses and terms.

## Collection Process

Probe rows were generated by asking each model for an initial MCQ answer and then re-asking under an 8-probe argument-strength by social-cue factorial. Debate rows were generated with a homogeneous three-agent, three-round standard debate scaffold unless explicitly marked otherwise. Closed-API rows include the provider metadata exposed at collection time; older sealed lanes have partial backend metadata and are marked as such in provenance tables.

## Preprocessing And Labeling

Answer extraction uses the parser documented in `README_REPRO.md` and Appendix C of the paper. No LLM judge step is used for answer extraction or transition labels. Debate outcomes are deterministically reduced to initial and final majority correctness, conditional collapse, correction, and onset where round traces are available. Unparsed answer states are audited separately; the primary analysis filters `None` answers before deterministic alphabetic tie-breaking and reports parser-failure and no-fallback cell-stability sensitivity.

## Intended Uses

- Recompute the paper's zero-API derived tables from checked-in traces.
- Populate a reuse card for a new model-scaffold pair.
- Compare debate interventions by prevented collapses, lost corrections, and weighted signed utility.
- Audit whether a model family or scaffold warrants richer trace logging before a full debate sweep.

## Out-Of-Scope Uses

- Treating alpha values as a standalone safety leaderboard.
- Treating the screen as a calibrated per-question collapse oracle.
- Training models to resist or exploit the convince-wrong probe templates.
- Claiming broad benchmark or scaffold transfer without a target-task calibration audit.

## Maintenance And Versioning

The initial release is versioned as `alpha-tot-v1.0`. The archived rows are immutable. Future closed-API reruns, provider snapshot changes, parser changes, or benchmark-pool revisions should be released as new minor versions with a changelog rather than overwriting the archived artifact. Each public version is archived with a DOI and cross-links the code repository, the open and gated datasets, this datasheet, and the metadata files.

## Known Limitations

The headline evidence is on MMLU-Pro with a homogeneous three-agent scaffold. Cross-benchmark rows are boundary or single-model stress checks, not broad transfer evidence. The primary inferential unit is family aggregation over a realized `G=7` cohort. Capability pressure is a strong comparator, and the screen should be read as a model-scaffold triage measurement rather than a capability-free construct. Per-model high-FR question pools are selected outcome-blind by probe behavior, but they are still a selection assumption that downstream reusers must report rather than silently inherit.
